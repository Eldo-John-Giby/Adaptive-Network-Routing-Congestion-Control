Abstract
This project develops a Python-first network simulation and analysis system that demonstrates the complete journey of data across the seven OSI layers while studying routing and congestion under changing network conditions. The system generates application data, performs encoding and session management, transports data using TCP or UDP, creates IP packets, adds MAC addressing and CRC-based error detection, and models bandwidth and transmission delay. A software network of configurable routers and links is used to simulate queueing, packet loss, delay and link failures. A machine-learning module learns from these network states to predict congestion and estimate route performance, allowing the system to choose better paths dynamically. The project combines Computer Networks laboratory concepts with machine-learning-based decision making and presents the results through a visual packet journey and performance dashboard.
